# Links dos artefatos

_Última atualização: 13/09/2026_

Páginas do projeto que **não são arquivos deste repositório**: são Artifacts, HTML publicado
e hospedado no claude.ai, cada um com link próprio. Procurar por elas nas pastas do
computador não acha nada — esta lista é o índice delas.

Quem mantém: você. Artefato novo entra aqui com o link e uma linha do que ele é.

---

## Em uso

- <https://claude.ai/code/artifact/46ec1a79-dc82-4ada-8fce-fa185a9cf4a3>
  **Bancada PIBITI** — o painel das 48 semanas do projeto, da Fase 0 à Fase 6. Marca tarefa
  por tarefa, guarda o que você marcou, tem campo de anotação por semana e um botão que copia
  um resumo do progresso para mandar ao orientador. Traz também a ordem de corte, se atrasar.

- <https://claude.ai/code/artifact/364f48f1-a2db-4fa3-b50c-f38fb7e9302a>
  **Próximas quatro semanas** — o plano de 14/09 a 11/10 em detalhe: o que fazer em cada
  semana, com que horas, mais as três perguntas da reunião de 16/09 e os quatro alvos de
  11/10. Substitui o planejamento de 02/09.

- <https://claude.ai/code/artifact/04f0da7c-37d6-48e5-ae04-a31ce173001b>
  **Roteiro da reunião** — as seis perguntas para o orientador, cada uma com a fala pronta e
  um "por que importa" que abre com o contexto e os números. **Tem campo para anotar a
  resposta dele na hora, e o que você digita fica salvo.** Leve aberto na reunião.

## Anteriores à mudança de escopo

Escritos em 02/09, antes de ficar decidido que as máquinas já digitalizam os dados e que o
Raspberry Pi sai do projeto. Continuam úteis pela parte de geotecnia; a parte de
instrumentação já não vale.

- <https://claude.ai/code/artifact/7167a3d4-3f87-44a4-9966-7b8561513691>
  **Do ensaio ao gráfico** — a base conceitual: o que é resistência ao cisalhamento, como as
  duas máquinas funcionam, os nove gráficos que o sistema precisa gerar e as seis decisões de
  cálculo onde o automatizado e o manual podem divergir. É a página para reler antes de
  programar qualquer cálculo.

- <https://claude.ai/code/artifact/3c11e075-5d13-47a7-99d5-ef4b44b2c76c>
  **PIBITI Cisalhamento IoT** — o primeiro planejamento do ano, 54 tarefas em 5 fases,
  montado em torno da aquisição por Raspberry Pi. **Superado** pela Bancada PIBITI; fica como
  histórico de como o projeto era pensado no começo.

## Como achar um artefato sem esta lista

- `/artifacts` no terminal do Claude Code — lista todos; `o` abre, `c` copia o link.
- <https://claude.ai/code/artifacts> — a mesma coisa no navegador.

O conteúdo dessas páginas é derivado dos documentos de `docs/`. Quando as duas coisas
divergirem, **o repositório é que vale** — a página pode estar velha.
